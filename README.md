# 视频模板 Video Template Studio

根据 After Effects 工程制作的浏览器视频模板工具。替换素材后可以预览动画、保存模板并导出无声视频，无需安装 AE。

## 现有页面 · 七套 AE 模板

- 课程卡片轮播1：替换卡片、分类标题和透明 PNG 拖尾。
- 长图横向滚动：上传长图，沿原动画横向移动。
- 痛点轮播：增减素材，下方指示 UI 随数量变化。
- 买家秀轮播：替换、增加或删除图片。
- 左右移轴对比：替换对比素材。
- 课程卡片轮播2：支持 1–12 张动态卡片，可增删并混合使用图片和视频；支持图片、MP4/WebM 视频及透明文案 PNG 替换。

- 浅色翻页轮播：四组横幅图片 / 视频与可编辑分类、标题、正文联动；保留 #ECEFF2 浅色背景、#EBB300 指示条、30% 非当前文字块和原始蓝色叠层。支持输入 HEX 色值，同步修改滑块与第一行文案的颜色；0–100% 透明度仅作用于四组文案最左侧的两个分类字。设置随模板保存及导出。默认 1500 × 1508、10 秒；按参考视频将卡片、指示条及文案整体上移 192 px，左右各留 74 px。

公共功能包括预览缩放、时间轴、背景颜色/图片、画面比例、时长、保存/打开 JSON 模板和导出视频。动画在浏览器 Canvas 中重建，部分模糊和阴影与 AE 渲染可能有细微差异。

## 其他来源 · 69 个动效模板

参考 Animos 公开编辑器的动画类型独立重建，分为三维透视（12）、多场景编排（13）、等距视角（3）、环绕轨道（8）、轮播流动（10）、网格排布（8）、焦点展示（4）、揭幕转场（4）、堆叠散落（7）。每个模板有不同的构图和运动，可混合使用 1–30 个图片/视频素材，并调整尺寸、间距、圆角、角度、纵深和速度。可叠加文字及 PNG Logo，保存/打开完整 JSON 工程。

界面使用三栏编辑器，支持深色/浅色切换并在当前浏览器记忆。模板来源切换保留编辑状态，不同动效各自保留参数、背景及时间。缩略图仅绘制可见项并缓存，避免同时加载所有原始素材。

这是独立 Canvas 实现，部分几何、节奏、阴影和曲面透视与参考网站有差异；不是 Animos 官方应用或源码副本。公开编辑器的账户、订阅及云端项目不在本地工具中。

## 本地运行

这是原生 HTML、CSS、JavaScript 静态项目，无需安装 npm 依赖或构建。安装 Python 3 后，在仓库根目录运行：

```sh
python -m http.server 8768 --directory dist --bind 127.0.0.1
```

浏览器打开 <http://127.0.0.1:8768>。建议使用支持 WebCodecs 的新版 Chrome / Edge；GIF 导出使用浏览器内置的 JavaScript 编码流程。请通过 HTTP 服务运行，避免直接双击 HTML 造成资源读取限制。

## 使用方法

1. 在左侧选择「现有页面」或「其他来源」，通过分组缩略图和搜索选择模板，在右侧点击素材进行替换。七套模板的主要画面均支持图片和 MP4/WebM 视频，可混合使用；有批量上传或增删功能的模板也支持视频。视频保持原速、自动循环，随时间轴播放或暂停。背景、拖尾和文案装饰仍使用图片。
2. 调整背景、时长和画面比例。支持原片预设或自定义宽高（128–4096 px 的偶数），画面内容可缩放 25%–300%，超出画布的部分裁切，导出同步应用。点击“恢复默认缩放”回到 100%；预览窗口的查看缩放不影响导出。
3. 点击“保存模板”下载包含图片、完整视频和参数的 JSON，以后用“打开模板”恢复。兼容之前保存的图片模板。
4. 点击“导出视频”，保持页面在前台，完成后下载成片。

视频导出不含声音；支持 MP4（H.264）、MOV（H.264）、WebM（VP9）和循环 GIF，导出窗口可选择帧率、分辨率和画质并显示文件大小。智能互联视频建议正方形，单个文件不超过 40 MB、时长不超过 2 分钟；文案建议为 1080 × 1620 透明 PNG。替换素材在当前浏览器内处理，项目无需后端或 API 密钥。

## 文件结构

```text
dist/
  index.html         页面入口
  style.css          原模板样式
  editor-layout.css  三栏编辑器与黑白主题
  studio.js          来源分类、图库、搜索及主题
  other.js           新增动效的素材管理、参数与工程保存
  other-renderers.js 69 个独立 Canvas 动效
  app.js             模板交互、绘制和导出
  smart.js           智能互联动态素材与绘制
  flip.js            浅色翻页画面、文案与透视绘制
  flip-motion.json   按需加载的 AE 翻页与文案透明度曲线
  *-motion.js        从 AE 提取的动画数据
  assets/            模板默认图片、视频与 UI 素材
```

部署时将 `dist` 作为静态站点根目录即可。本仓库包含当前网页版本及运行素材，不包含 AE 源工程、私人部署配置和本机路径。

仓库公开不代表默认品牌、人物、图片及视频素材获得额外授权；这些素材的权利归原权利人所有。

默认素材按模板加载，已打开的模板复用内存缓存。11 张大图使用保持尺寸及像素不变的无损 WebP，原始 PNG 仍保留。首屏默认图片资源由约 63.7 MB 降至 0.87 MB（不含脚本、样式；实际加载时间取决于网络）。


浅色翻页轮播采用 WebCodecs 逐帧生成 H.264 MP4，并将像素实际转换为 BT.709 标准视频范围（I420），避免全范围录制文件在部分剪辑软件中出现浅灰背景发白。需支持 WebCodecs 的 Chrome / Edge；Mediabunny 1.61.4 仅在导出时按需加载，许可证位于 dist/vendor。
