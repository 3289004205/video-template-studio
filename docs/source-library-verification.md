# 其他来源动效整合记录

参考页面：https://animos.app/editor 。公开编辑器观察日期：2026-10-20。

## 观察与实现

公开界面显示 9 个分组、69 个模板、图片/视频槽位、比例、时长、文字/Logo、背景及参数控件。模板名称和分组用于建立对应目录；几何及时间行为以独立 Canvas 2D 代码实现，三维圆环采用网格贴图与透视投影。没有嵌入外站 iframe、账户系统、订阅接口或默认素材。新增占位图片在浏览器生成。

REA 分析的是公开前端入口，证据 ev_6433a1d9521912b848df73bf47deb5e0780e7a8f0da2bbe46f3224407f9a68cb；语法提取成功，语义图因 worker 内存限制覆盖不完整，不能用于声称已还原整站所有运行行为。实际可见目录与浏览器预览另行验证。独立重建与原站的几何和动画节奏允许存在差异。
